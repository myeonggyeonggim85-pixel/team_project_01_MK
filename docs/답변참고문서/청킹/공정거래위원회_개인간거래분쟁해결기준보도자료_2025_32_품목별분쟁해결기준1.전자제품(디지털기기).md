## 품목별 분쟁해결기준: 1. 전자제품(디지털기기)

| 분쟁 유형 | 해결 기준 |
|---|---|
| **1) 판매자가 고지하지 않은 중대한 하자가 있는 경우** | |
| - 물건 수령 후 24시간 이내에 하자를 발견한 경우 | o 구입가 및 운송료 환급 또는 수리비 배상 |
| - 물건 수령 후 7일 이내에 정상적인 사용상태에서 발생한 성능・기능상의 하자 | o 구입가 50% 이내 환급 또는 수리비 70% 중 적은 금액 이내 배상 |
| - 물건 수령 후 14일 이내에 정상적인 사용상태에서 발생한 성능・기능상의 하자 | o 구입가 30% 또는 수리비 50% 중 적은 금액 이내 배상 |
| - 물건 수령 후 14일 이후에 정상적인 사용상태에서 발생한 성능・기능상의 하자 | o 분쟁발생 경과, 하자 정도 등 종합적인 제반 사항을 고려하여 판단 |
| **2) 판매자가 고지하지 않은 경미한 하자가 있는 경우** | |
| - 물건 수령 후 24시간 이내에 하자를 발견한 경우 | o 수리비 배상 |
| - 물건 수령 후 7일 이내에 정상적인 사용상태에서 발생한 성능・기능상의 하자 | o 구입가 20% 또는 수리비 30% 중 적은 금액 이내 배상 |
| - 물건 수령 후 14일 이내에 정상적인 사용상태에서 발생한 성능・기능상의 하자 | o 구입가 10% 또는 수리비 20% 중 적은 금액 이내 배상 |
| - 물건 수령 후 14일 이후에 정상적인 사용상태에서 발생한 성능・기능상의 하자 | o 분쟁발생 경과, 하자 정도 등 종합적인 제반 사항을 고려하여 판단 |
| **3) 판매자가 구매자에게 물건을 인도하는 과정에서 운송업자 등 제3자의 귀책사유 또는 천재지변 등 불가항력적인 사유로 멸실 또는 훼손된 경우** | |
| - 물건이 분실된 경우 | o 구입가 환급 |
| - 물건이 훼손된 경우 ㆍ 수리가 가능한 경우 | o 수리비 배상 |
| - 물건이 훼손된 경우 ㆍ 수리가 불가능한 경우 | o 구입가 환급 |
